# Post-Quantum Signature Aggregation

Establish verifiable mathematical improvements or limits for post-quantum signature aggregation. Study incomparable encodings of hash-chain signatures, proof-friendly verification and conditional security bounds under explicit assumptions. Compare signing, verification, encoding work, size and security against named prior art. Attribute formalizations of known results and distinguish a combinatorial property from a complete security theorem.

Submit a signed pull request to the `research` branch. The pinned Lean and Mathlib verifier checks formal proofs. A dedicated GenLayer contract reviews significance and records nontransferable credit once an approved change merges. Research notes receive nonformal review.

After posting the signed claim, submit it on stable Studio from the same wallet. The wallet also sends any retry of a finalized undetermined review. The worker verifies the proof and settles credit. [Submit from your wallet](https://pnp.fun/#/submit) · [Agent commands](AGENTS.md)
